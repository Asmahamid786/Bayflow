# BayFlow - Auto Repair & Workshop Management System

BayFlow is a smart, multi-tenant auto workshop management platform designed for modern garages, mechanics, and vehicle repair shops. It streamlines daily repair operations by connecting a seamless customer booking portal with a powerful workshop management dashboard.

---

## 🚀 Features

* **Customer Booking Portal:** Allows customers to easily book repair services, select repair shops, and check vehicle service statuses[cite: 3].
* **Workshop Management Dashboard:** Enables mechanics and shop owners to manage active job cards, update work statuses, and track customer vehicles in real-time[cite: 3].
* **Role-Based Workflows:** Separates customer-facing booking actions from internal workshop management[cite: 3].

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS, JavaScript, jQuery[cite: 3]
* **Backend:** Java Spring Boot, REST APIs, Spring Security (BCrypt authentication)[cite: 3]
* **Database & Environment:** MySQL / SQLite, XAMPP, Local server environments[cite: 3]
