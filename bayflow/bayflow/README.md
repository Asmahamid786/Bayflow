# BayFlow - Multi-Tenant Auto Repair Shop Management Platform

BayFlow is a multi-tenant platform for independent auto repair shops, enabling customers to discover shops, book services, and track vehicle repairs in real-time while staff manage jobs via a role-based shop POS[cite: 1, 3, 7].

---

## Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA, REST APIs, H2 / PostgreSQL
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Fetch API)

---

## Prerequisites
- Java JDK 17 or higher
- Maven (for running the Spring Boot backend)
- A modern web browser
